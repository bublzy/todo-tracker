# Трекер задач

Персональный TODO-трекер на GitHub Pages: **https://bublzy.github.io/todo-tracker/**

- `gh-pages` — сам сайт (`index.html`, без сборки и зависимостей).
- `data` — данные (`tracker.json`). Каждое изменение — отдельный коммит, поэтому `git log data` и есть полная история разработки.

Страница опрашивает GitHub API (с ETag, поэтому неизменившиеся ответы не тратят лимит) и показывает изменения через несколько секунд.
Задачи обновляет Claude через скилл `tracker` (`~/.claude/skills/tracker`), а с токеном в настройках страницы — и вы сами.

Репозиторий публичный: не пишите в задачи секреты.
